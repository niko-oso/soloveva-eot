# Деньги как сценарий — эмоционально-образный практикум

Лендинг практикума Лилии Леоновой (ЭОТ).

Сайт — один файл `index.html`: стили и скрипты встроены внутрь, изображения подключаются с CDN Тильды (static.tildacdn.com). Исходники картинок — в папке `img/`.
Шрифты Prata и Onest подключаются из Google Fonts.

## Публикация на GitHub Pages
Settings → Pages → Build and deployment → Source: «Deploy from a branch» → Branch: `main`, папка `/ (root)` → Save.
